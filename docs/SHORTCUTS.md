# Keyboard Shortcuts Reference

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+1` | Go to Dashboard |
| `Ctrl+2` | Go to Chart |
| `Ctrl+3` | Go to Watchlist |
| `Ctrl+4` | Go to Signals |
| `Ctrl+5` | Go to Orders |
| `Ctrl+6` | Go to Portfolio |
| `Ctrl+7` | Go to Risk Dashboard |
| `Ctrl+8` | Go to AI Agents |
| `?` | Show help overlay |

## Windows

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New window |
| `Ctrl+Shift+N` | New window (cross-tab sync) |

## Interface

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+D` | Toggle distraction-free mode (hides all chrome) |
| `Ctrl+Shift+R` | Toggle right sidebar (news, calendar, chat) |
| `Ctrl+Shift+C` | Toggle chat/terminal interface mode |
| `Ctrl+K` | Open command palette |

## Tabs

| Shortcut | Action |
|----------|--------|
| `Ctrl+Tab` | Next tab |
| `Ctrl+Shift+Tab` | Previous tab |
| `Ctrl+W` | Close current tab |

## Chart

| Shortcut | Action |
|----------|--------|
| `←` / `→` | Scroll chart left/right |
| `Shift+←` / `Shift+→` | Scroll chart faster |
| `+` / `-` | Zoom in/out |
| `Ctrl+Z` | Undo drawing |
| `Ctrl+Shift+Z` | Redo drawing |
| `Delete` | Remove selected drawing |

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl+P` | Quick symbol search |
| `Escape` | Close modals / deselect |
| `Ctrl+R` | Hard refresh data |

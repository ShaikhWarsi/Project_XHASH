## Getting Started

### What is Trading Engine?

Trading Engine is an all-in-one trading platform that combines:
- **Quantitative signals** — 23+ signal engines for market analysis
- **AI agents** — Hedge fund personas, LLM analysts, Renaissance-style teams
- **Risk management** — Position limits, stop-loss, circuit breakers
- **Backtesting** — Test strategies against historical data
- **Paper trading** — Practice trading without real money
- **Live trading** — Connect to Alpaca, CCXT, or Interactive Brokers

### System Requirements

| Component | Requirement |
|-----------|-------------|
| Python | 3.11 or higher |
| Node.js | 18 or higher |
| RAM | 8GB minimum (16GB recommended) |
| Disk | 2GB free space |
| OS | Windows, macOS, or Linux |

### Installation

**Step 1: Install Python dependencies**

Open a terminal and run:
```bash
pip install -e ".[dev,llm,live,ml]"
```

This installs the core engine, LLM support, live trading, and machine learning features.

**Step 2: Install frontend dependencies**

```bash
cd frontend
npm install
```

**Step 3: Configure environment variables**

```bash
cp .env.example .env
```

Edit `.env` with your API keys (optional — most features work without them).

### Running the Application

**Start the API server:**
```bash
python scripts/dashboard.py
```
The API starts on `http://localhost:8000`. Keep this terminal open.

**Start the frontend (in a second terminal):**
```bash
cd frontend
npm run dev
```
Open `http://localhost:5173` in your browser.

### First Launch

When you first open the app, you'll see a **Quick Start Guide** popup. This guide will help you:
1. Check system health (look at the status bar at the bottom)
2. Run your first backtest
3. Explore the features

If you see a **"Startup Issues Detected"** notification, click it to see what needs to be fixed.

### Risk Dashboard (`/risk`)

Monitor your portfolio's risk in real-time.

**Key metrics:**
| Metric | What it means |
|--------|-------------|
| **VaR 95%** | Maximum loss expected 95% of the time |

| **Sortino Ratio** | Like Sharpe but only considers downside |

| **Profit Factor** | Gross profit / gross loss |

**Risk controls:**
- **Circuit Breaker** — Automatically stops trading if losses exceed threshold
- **Position Limits** — Maximum position size per symbol
- **Stop-Loss** — Auto-exit at a loss level
- **Kelly Sizing** — Optimal position size based on win rate

### Attribution Analysis (`/risk/attribution`)

Break down your returns by:

- **Security selection** — Which picks helped/hurt
- **Timing** — Entry/exit timing impact

## Strategy & Backtesting

### Backtest (`/strategy/backtest`)

Test a trading strategy against historical data before trading it live.

**How to run a backtest:**
1. Enter tickers (e.g., `AAPL,MSFT`)
2. Choose date range
3. Set initial capital
4. Select strategy
5. Click **Run Backtest**

**Understanding results:**
| Metric | Description |
|--------|-------------|
| **Total Return** | Overall profit/loss percentage |
| **Annualized Return** | Return per year |
| **Sharpe Ratio** | Risk-adjusted return |
| **Max Drawdown** | Biggest loss from peak |
| **Win Rate** | % of profitable trades |
| **Profit Factor** | Gross profit / gross loss |
| **Number of Trades** | Total trades executed |
| **Avg Trade Duration** | How long trades last on average |

**The equity curve** shows your portfolio value over the backtest period. Green markers show profitable trades, red markers show losses.

### Strategy Lab (`/strategy/lab`)

Build strategies visually without coding. Drag and drop conditions to create trading rules.

### FinScript (`/strategy/code`)

Write custom strategies using FinScript — a simple trading DSL (Domain Specific Language). It supports:
- 40+ built-in functions
- Technical indicators
- Entry/exit conditions
- Position sizing

**Example FinScript:**
```
strategy "Golden Cross"
when crossover(sma(close, 50), sma(close, 200)) then
  buy 100 shares
when crossunder(sma(close, 50), sma(close, 200)) then
  sell all
```

### Strategy Optimizer (`/strategy/optimizer`)

Automatically find the best parameters for your strategy using:
- **Grid Search** — Try all combinations of parameters
- **Random Search** — Try random combinations (faster)
- **Walk-Forward Analysis** — Test robustness across time periods

### Visual Strategy (`/strategy/visual`)

Create strategies using a node-based visual editor. Drag, connect, and configure nodes to build trading logic.

## Troubleshooting

### "API Server Not Running" / Connection Dots Are Red

The frontend can't reach the backend API server.

**Fix:** Open a terminal and run:
```bash
python scripts/dashboard.py
```
Wait for it to say "Application startup complete." Then refresh the browser.

### "LM Studio Not Running"

AI agent features require LM Studio running locally.

**Fix:**
1. Download and install LM Studio from [lmstudio.ai](https://lmstudio.ai)
2. Open LM Studio and load a model
3. Make sure the local server is running on port 1234
4. Check `LMSTUDIO_BASE_URL` in your `.env` file

### No Market Data / Charts Are Empty

The system couldn't fetch price data.

**Possible causes:**
1. **API server is down** — Run `python scripts/dashboard.py`
2. **No internet** — Check your connection
3. **Symbol doesn't exist** — Verify the ticker symbol
4. **Rate limited** — Wait a moment and try again

### Backtest Results Are Empty

The backtest didn't produce any trades.

**Possible causes:**
1. **Date range too short** — Try at least 1 year of data
2. **Strategy conditions not met** — The strategy may not trigger on the selected symbol
3. **No price data** — Check the symbol is valid
4. **Capital too low** — Increase initial capital

### WebSocket Disconnects

Real-time data keeps disconnecting.

**Fixes:**
1. Check your internet connection
2. Check if a firewall is blocking WebSocket connections
3. The system will auto-reconnect within 30 seconds
4. If persistent, restart the API server

### "Too Many Requests" Error

You're hitting the rate limit (100 requests per minute).

**Fix:** Wait about 30 seconds and try again. The rate limit resets every minute.

### Feature Not Working After Fresh Install

Some features require initial setup:

1. **Signals empty** — Signal engines run in the background. Wait 1-2 minutes for initial computation.
2. **Trades empty** — No trades yet. Place a paper trading order first.
3. **Portfolio empty** — Start paper trading or place an order.
4. **AI not responding** — Check your LLM API keys in Settings.

### Getting Help

If you encounter an issue not covered here:
1. Check the **Debug page** (`/debug`) for system info
2. Look at the **Status Bar detail** (click the expand button)
3. Check browser console for errors (F12 → Console tab)
4. Run health check: `curl http://localhost:8000/health/detailed`
5. Report issues at the project repository

# Examples

This directory contains example scripts and SDK usage guides for interacting with the X_KA_HASH / OpenAlgo-compatible API.

## Python

| File | Description |
|------|-------------|
| `python/ltp_example.py` | Get Last Traded Price for a symbol |
| `python/place_order.py` | Place a buy/sell order via the API |
| `python/supertrend.py` | SuperTrend indicator calculation |
| `python/heatmap.py` | Heatmap visualization using Plotly |
| `python/ema_crossover.py` | EMA crossover strategy logic |
| `python/webhook_server.py` | Receive TradingView/ChartInk webhook alerts |
